# ETF 份额统计日期修复

日期：2026-10-14，分支：cn。

## 行为

- 采集与展示快照允许源报表明确标注的当天日期，历史查询结束日包含当天；未来日期继续拒绝。
- 保留统计日期、上一交易日和获取日期各自的含义，抓取时间不能替代统计日期。
- 份额抓取独立于 PCF 限额和历史基线。当前源失败、只提供旧数据或缺少相邻交易日时，继续尝试历史源，每轮最多两次下载。
- 相同代码和日期的新源记录覆盖旧份额缓存。缺少经交易日历确认的上一交易日时，新增值保持空。
- 当天快照使用当天已采集的限额及申赎状态；历史快照使用对应日期的历史状态和限额。历史 SZSE PCF 可复用经过历史身份和形态校验的过期缓存，不回源、不串日期。
- 同日份额新增事件与同日限额事件合并，避免覆盖已生成的检查结果。
- 补回线上已有的 13 只基金、申购推算、PCF 前期净值和现金差额字段；SSE 缺少份额源时维持空值。
- 前端展示获取日期和申购推算说明。申赎同时开放时，净增不等于实际总申购；金额仍等待带统计日期的净值证据。
